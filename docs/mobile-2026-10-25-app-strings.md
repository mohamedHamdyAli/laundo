# تغيير API — نصوص كل تطبيق من السيرفر: `GET /translations/app?app=…`

**التاريخ:** ٢٥ أكتوبر ٢٠٢٦
**لـ:** فريق تطبيق العميل وفريق تطبيق المندوب
**الحالة:** ✅ **شغال على laundo.nahrdev.net** من ٢٥ أكتوبر ٢٠٢٦ (`209725e`).

---

## الخلاصة

ملفات الترجمة الأربعة اللي بعتوها (`user_ar.json` و`user_en.json` و`driver_ar.json` و`driver_en.json`)
بقت على السيرفر، والإدارة تقدر تعدّل أي نص فيهم من اللوحة من غير ما تنزّلوا نسخة جديدة.
الـ endpoint بقى **محتاج تقولوله إنتو أنهي تطبيق**:

```http
GET /api/v1/translations/app?app=user&code=ar     ← تطبيق العميل
GET /api/v1/translations/app?app=driver&code=ar   ← تطبيق المندوب
```

| البراميتر | |
|---|---|
| `app` | **إجباري.** `user` أو `driver` بالظبط (حروف صغيرة). لو ناقص أو غلط: **422** و`errors.app` |
| `code` | اختياري. كود اللغة؛ لو مبعتّهوش بياخد لغة هيدر `lang` |

مفتوح من غير توكن، عشان التطبيق محتاج نصوصه قبل تسجيل الدخول.

## شكل الرد

```json
{
  "key": "success",
  "status": "success",
  "msg": "",
  "code": 200,
  "data": {
    "code": "ar",
    "type": "app",
    "app": "driver",
    "strings": {
      "app_name": "لاوندو - السائق",
      "login": { "title": "تسجيل دخول السائق", "...": "..." },
      "tasks": { "count": { "zero": "لا مهام", "one": "مهمة واحدة", "two": "مهمتان", "few": "{} مهام", "many": "{} مهمة", "other": "{} مهمة" } }
    }
  }
}
```

- **`strings` هو ملفكم بالظبط بنفس الشكل** (متداخل، و`{}` و`{name}`، والجمع) — تقدروا تحطّوه مكان الملف المدمج.
- **كل مفاتيح الملف الإنجليزي موجودة دايمًا.** لو مفتاح ناقص في العربي (أو لغة جديدة لسه متترجمتش)، بيرجع بالإنجليزي، عمره ما يرجع ناقص.
- **مفيش مفاتيح جديدة بتتضاف من اللوحة.** الإدارة بتعدّل النصوص بس. لو ضفتوا مفتاح في التطبيق، ابعتوا الملف الجديد وإحنا نرفعه.
- الإدارة مش هتقدر تحط في نص `{...}` مش موجود في الإنجليزي، ولا `{}` أكتر من الإنجليزي. ممكن يكون فيه **أقل** (زي «منذ دقيقتين» من غير رقم).

ولو `app` ناقص أو غلط:

```json
{
  "key": "validation_error",
  "status": "error",
  "msg": "حدد التطبيق اللي بيطلب: app=user أو app=driver.",
  "code": 422,
  "errors": { "app": ["حدد التطبيق اللي بيطلب: app=user أو app=driver."] }
}
```

## المطلوب من كل فريق

| | تطبيق العميل | تطبيق المندوب |
|---|---|---|
| الطلب | `?app=user` | `?app=driver` |
| اللغة | `code` أو هيدر `lang` | `code` أو هيدر `lang` |
| ✓ | يدمج `strings` فوق ملفه | يدمج `strings` فوق ملفه |

## اقتراح للتطبيق

١. اشتغلوا بالملف المدمج زي دلوقتي.
٢. اطلبوا `GET /translations/app?app=…&code=<اللغة>` في الخلفية، وخزّنوا الرد.
٣. حطّوا `strings` فوق الملف المدمج (اللي في الرد يكسب)، واستخدموا المخزّن في الفتحة الجاية.

## اللي اتغيّر عن قبل كده

`/translations/app` من غير `app` كان بيرجّع `{}` فاضية (ملف `_mobile` اللي ماحدش ملاه). **دلوقتي بيرجّع 422.**
لو حد بيناديه من غير `app`، يضيفه.

## ملاحظة على ملف المندوب العربي

`card.qr_title` و`card.qr_subtitle` لسه بالإنجليزي في `driver_ar.json`
(«Order Confirmation Success» و«Scan to View Details & Track»). اتسابوا زي ما هم؛ لو عايزينهم بالعربي ابعتوهم أو الإدارة تعدّلهم من اللوحة.

## Postman

طلب **Translations** بقى فيه `app=user`، ووصفه اتحدّث.
