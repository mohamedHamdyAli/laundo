# تغيير API — لينكات السوشيال كقايمة في `GET /app-settings`

**التاريخ:** ١١ أكتوبر ٢٠٢٦
**لـ:** فريق تطبيق العميل وفريق تطبيق المندوب
**الحالة:** ⏳ جاهز، لسه ما اتنشرش على laundo.nahrdev.net.

## الخلاصة

`GET /api/v1/app-settings` فيه حقل جديد **`social`**: لينكات السوشيال اللي الإدارة مالياها في
الإعدادات، كقايمة جاهزة تلفّوا عليها وترسموا أيقونة لكل صف. مفيش حاجة اتشالت.

```json
"social": [
  { "key": "whatsapp", "label": "واتساب", "url": "https://wa.me/201000000000" },
  { "key": "facebook", "label": "فيسبوك", "url": "https://facebook.com/laundo.eg" }
]
```

| الحقل | |
|---|---|
| `key` | ثابت، اختاروا الأيقونة بيه: `whatsapp`، `facebook`، `instagram`، `twitter`، `snapchat`، `youtube`، `linkedin`، `gmail` |
| `label` | اسم المنصة بلغة الطلب (هيدر `lang`) |
| `url` | اللينك زي ما الإدارة كتبته، وبيبدأ دايمًا بـ `http://` أو `https://` |

- **الترتيب ثابت** زي الجدول فوق.
- **اللينكات الحقيقية بس.** اللينك اللي لسه شايل قيمة القالب (زي `http://facebook.com/`، اللي بيفتح صفحة فيسبوك الرئيسية مش صفحتنا) **مش بيظهر في القايمة**.
- **القايمة ممكن تكون فاضية** `[]` لو الإدارة لسه ماملتش أي لينك. ده الحاصل على السيرفر النهارده، لحد ما تتملا من الإعدادات.
- تطبيق المندوب (`?audience=driver`): لينك الواتساب في القايمة هو رقم المندوبين، زي `whats_app` بالظبط. ولو واتساب المندوبين فاضي أو قيمة قالب، بيرجع واتساب العملاء. ولو مكتوب رقم من غير لينك، بيظهر في `whats_app` بس ومش في القايمة، لأنه مش لينك يتفتح.

## تغيير صغير في الحقول القديمة

`facebook_url` و`instagram_url` و`twitter_url` و`snapchat_url` و`youtube_url` و`linkedin_url` و`gmail_url`
و`whats_app` لسه موجودين زي ما هم، بس **اللي شايل قيمة القالب بقى بيرجع `null`** بدل اللينك الوهمي.
لو بترسموا من الحقول دي، اخفوا الأيقونة لما القيمة `null`. والأحسن تنقلوا لـ `social`.
